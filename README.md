# Laternenland

Monster zähmen, füttern und züchten – ein Pixel-Abenteuer im HD-2D-Stil. Dieses Repo enthält nur die fertige Web-App.

**Spielen:** https://patrickstaudigl-pixel.github.io/laternenland/

## Als App installieren
- **Android (Chrome, Edge, Samsung Internet):** Adresse öffnen → im Titelbild „Als App installieren“ antippen (oder Browser-Menü ⋮ → „App installieren“).
- **iPhone / iPad:** Adresse in **Safari** öffnen → „Teilen“ (Quadrat mit Pfeil nach oben) → „Zum Home-Bildschirm“ → „Hinzufügen“.
  Kommt der Link über WhatsApp & Co., zuerst „In Safari öffnen“ wählen.
- **Computer (Chrome, Edge):** Installieren-Symbol rechts in der Adressleiste.

Die App startet im Vollbild, läuft auch ohne Internet und aktualisiert sich von selbst (Hinweis antippen → Neustart).

## Spielstand
- Wird automatisch auf dem Gerät gespeichert. Ab und zu sichern: Optionen → Spielstand → „Als Datei sichern“.
- Auf ein anderes Gerät mitnehmen: Optionen → Spielstand → „Code kopieren“, dort im Titelbild „Spielstand-Code laden“.
- Auf dem iPhone haben Safari und die Home-Bildschirm-App getrennte Speicher – am besten nur in der App spielen.
