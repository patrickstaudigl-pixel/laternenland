# KI-Vorlagen (Arbeitszweig)

Vorlagen für die KI-Neuzeichnung der Laternenland-Monster (eigene Designs): das bisherige Stufe-4-Ruhebild jeder Art,
pixelgenau vergrößert auf dunklem Grund. Nur Arbeitsdateien für die Bildbearbeitung – nicht Teil des Spiels.
Dieser Zweig wird von Veröffentlichungen des Spiels (main) nicht berührt.

## portraets/
Vorlagen für die KI-Porträts der Figuren (eigene Designs): das bisherige Dialog-Porträt (48×48 Einheiten) im Maßstab 15
(720×720) auf einer Schlüsselfarbe (Grün oder Blau, je Figur die mit dem größten Abstand zu Haar und Kleidung), Hochformat
9:16 (720×1280, Büste unten bündig, oben Luft für Haar und Hüte).
